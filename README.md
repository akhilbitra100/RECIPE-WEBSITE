Recipe Website

🍲 Project Overview

Recipe Website is a full-stack web application developed using ASP.NET that allows users to explore, upload, and manage different food recipes through an interactive and user-friendly platform.

The project is designed for food lovers, home cooks, and chefs who want to discover new recipes and share their own cooking ideas online. Users can browse recipes, search by categories, view ingredients and cooking instructions, and upload recipes with images.

🗂️ Project Structure

Frontend – Built using HTML, CSS, JavaScript, and Bootstrap for a responsive and interactive user interface

Backend – ASP.NET and C# for handling application logic and server-side operations

Database – SQL Server for storing user accounts, recipes, categories, and images

Image Management – Supports recipe image upload and storage functionality

🎯 Objectives

Provide an online platform for sharing and exploring recipes
Allow users to upload and manage their own recipes
Enable easy recipe search and category-based browsing
Deliver a clean and user-friendly cooking experience
Demonstrate web development concepts using ASP.NET

🧩 Key Features

User authentication and authorization
Add, edit, and delete recipes
Recipe image upload functionality
Search and filter recipes
Category-wise recipe browsing
Detailed ingredients and cooking instructions
Responsive UI design
Secure database integration

🛠️ Tools & Technologies

Frontend: HTML, CSS, JavaScript, Bootstrap

Backend: ASP.NET, C#

Database: SQL Server

Version Control: Git & GitHub

🚀 How to Run the Project

Clone the repository
Open the project in Visual Studio
Configure the SQL Server database connection
Restore required NuGet packages
Build and run the ASP.NET application
Open the application in your browser

📌 Use Cases

Online recipe sharing platform
Food blogging and recipe management
Academic mini/final-year project
Learning ASP.NET web development
